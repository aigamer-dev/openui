# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-01-02
### Added
- Initial release of OpenUI CLI.
- **Codebase RAG Engine**: Retrieval-augmented UI discovery.
- **Multi-OS Support**: Binaries for Linux, Windows, and macOS.
- **GitHub Actions**: Automated release pipeline.
- **Developer Directives**: Granular control via `// openui-ignore` and `@openui_include`.
- **Manual Overrides**: Support for `openui.overrides.json`.
- **Audit System**: Quantitative element-level analysis.
