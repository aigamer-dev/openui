# Contributing to OpenUI

Thank you for your interest in contributing to OpenUI! This project aims to automate UI discovery through Codebase RAG.

## How to Contribute

1.  **Fork the Repository**: Create a personal fork of the repo.
2.  **Create a Branch**: Use a descriptive name for your branch (e.g., `feature/custom-framework`).
3.  **Make Your Changes**: Write clean, documented code.
4.  **Submit a Pull Request**: Provide a detailed description of your changes.

## Development Setup

1.  Install Python 3.10+.
2.  Install dependencies: `pip install .`
3.  Run the CLI: `python openui_gen.py --help`
4.  Build locally: `python build.py`

## Pull Request Guidelines

*   Ensure all tests pass (if applicable).
*   Update the `CHANGELOG.md` with your changes.
*   Follow the existing code style.
